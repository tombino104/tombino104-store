# tombino104-store

A community app store for umbrelOS.

| App | What it is |
| --- | --- |
| Personal OS | Discipline, without the dopamine tricks |
| Homelab Savings | What your homelab saves you |
| MiniQR | Create and scan QR codes |
| VibraVid | Search and download streaming videos |
| OpenSEO | Open source alternative to Semrush and Ahrefs |
| HyCanvas | Self-hosted Canva alternative |
| Chatwoot | Open source customer support desk |
| Colanode | Local-first Slack and Notion alternative |
| TaxHacker | Self-hosted AI accounting for receipts and invoices |
| Upersite CRM | Clients, quotes, payments, tasks and automations |

To use it, open the umbrelOS App Store, choose the menu at the top right, **Community App Stores**, and add `https://github.com/tombino104/tombino104-store`.

Third-party apps are kept up to date by a daily GitHub Action. How it works, and how to add an app, is in [AGENTS.md](AGENTS.md).
